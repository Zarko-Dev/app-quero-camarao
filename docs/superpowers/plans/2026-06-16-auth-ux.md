# Auth UX — Register Button + Password Recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tornar o botão "CADASTRAR-SE" um botão visível de verdade, e dar destaque real ao link "Recuperar Senha" na tela de Login.

**Architecture:** Mudanças puramente de UI em `src/pages/Login`. O botão de cadastro atual é só texto inline (`TextButtonRegister` dentro de `ContentTextRegister`) — sem background, sem height, sem visual de botão. O link de recuperação está escondido como texto secundário. Ambos precisam de styled-components novos ou atualizados.

**Tech Stack:** React Native, styled-components/native, expo

### Task 1: Botão CADASTRAR-SE mais relevante

**Contexto:** Atualmente:
```js
// Login/index.jsx linha 138-144
<ContentTextRegister>
    <TextRegister>Não tem uma conta? </TextRegister>
    <ButtonRegister>
        <TextButtonRegister onPress={handleRedirectRegister}>
            CADASTRAR-SE
        </TextButtonRegister>
    </ButtonRegister>
</ContentTextRegister>
```
`ButtonRegister` é `TouchableOpacity` sem nenhum estilo visual (sem background, sem border). `TextButtonRegister` é apenas texto em `colors.primary`. Resultado: usuário não percebe que é clicável.

**Solução:** Criar um `ButtonRegisterFull` com background branco, borda laranja, altura de 50px — mesmo tamanho do `ButtonLogin` — e colocá-lo abaixo do "Entrar".

**Files:**

### Task 2: Recuperação de senha mais proeminente

**Contexto:** O link "Esqueceu a senha? Recuperar" está como texto inline discreto:
```js
<ContentTextRegister>
    <TextRegister>Esqueceu a senha? </TextRegister>
    <ButtonRegister onPress={handleRedirectResetPassword}>
        <TextButtonRegister>Recuperar </TextButtonRegister>
    </ButtonRegister>
</ContentTextRegister>
```
Usuários no final do evento ("último sorteio") esquecem a senha e não encontram onde recuperar. Precisamos dar mais destaque.

**Solução:** Mover "Esqueceu sua senha?" para uma linha dedicada com ícone + texto maior, posicionada logo abaixo do campo de senha (mas acima do botão "Entrar"), com padding suficiente para ser clicável facilmente em mobile.

**Files:**
- Modify: `src/pages/Login/styles.js`
- Modify: `src/pages/Login/index.jsx`

- [ ] **Step 1: Adicionar `ForgotPasswordRow` ao styles.js**

Em `src/pages/Login/styles.js`, adicionar:

```js
export const ForgotPasswordRow = styled.TouchableOpacity`
    width: 100%;
    align-items: flex-end;
    padding-vertical: ${({ theme }) => theme.size.componentSize(8)};
    padding-horizontal: 2px;
`;

export const ForgotPasswordText = styled(Text)`
    font-size: ${({ theme }) => theme.size.fontSize(13)};
    color: ${({ theme }) => theme.colors.primary};
    font-weight: 600;
`;
```

- [ ] **Step 2: Atualizar o import no Login/index.jsx**

Adicionar `ForgotPasswordRow` e `ForgotPasswordText` ao bloco de imports (junto com o que foi adicionado na Task 1).

- [ ] **Step 3: Substituir o bloco atual "Esqueceu a senha"**

Em `Login/index.jsx`, dentro de `<ContentFormLogin>`, localizar:

```js
<ContentTextRegister>
    <TextRegister>Esqueceu a senha? </TextRegister>
    <ButtonRegister onPress={handleRedirectResetPassword}>
        <TextButtonRegister>Recuperar </TextButtonRegister>
    </ButtonRegister>
</ContentTextRegister>
```

Substituir por:

```js
<ForgotPasswordRow onPress={handleRedirectResetPassword}>
    <ForgotPasswordText>Esqueceu sua senha? Recuperar</ForgotPasswordText>
</ForgotPasswordRow>
```

- [ ] **Step 4: Verificar visualmente**

Na tela de Login, confirmar:
- "Esqueceu sua senha? Recuperar" aparece alinhado à direita, logo abaixo do campo de senha
- O texto está em laranja (primary color), claramente clicável
- Clicar navega para a tela de recuperação de senha
- Os dois campos (Email e Senha) + link de recuperação ficam agrupados logicamente
- O botão "Entrar" e "Cadastrar-se" ficam na seção Footer abaixo
