# System Architecture

## Core Tech Stack
- **Framework:** React Native with Expo
- **Language:** JavaScript
- **Backend/Services:** Firebase (Storage, Firestore, Functions)

## Testing & Tooling
- Test Runner: Node internal test runner (`node --test`)
- Static Analysis: ESLint
- Package Manager: Uses both Yarn and npm conventions (preferably Yarn for React Native apps typically, but we should support both).
